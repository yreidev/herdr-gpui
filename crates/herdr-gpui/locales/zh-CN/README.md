# 简体中文译文

每个 `<模块>.zh-CN.yml` 收一个模块的译文，几个模块共用的放 `common.zh-CN.yml`；
同一条英文只能出现在一个文件里。

## 翻译标准

意思准确、读来像中文软件的原生说法、同一术语全程一致、尽量简短。

- 系统菜单沿用 macOS / Windows 中文版的原词：剪切、复制、粘贴、全选、最小化、
  隐藏其他、全部显示、退出。
- 产品名、品牌名、布局名（Superset、Orca）和快捷键不译。
- 中文和英文、数字之间留一个空格；标点用全角，省略号用“…”。
- 列举用顿号“、”。
